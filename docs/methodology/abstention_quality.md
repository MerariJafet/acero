# Methodology — Abstention Quality

Abstaining on insufficient data is correct, not a failure. ACERO measures good abstentions
(abstained on a case it would have gotten wrong), unnecessary abstentions (abstained on a
case it would have gotten right), errors avoided, coverage, selective accuracy, and an
abstention utility (errors avoided − unnecessary abstentions). Thresholds may be learned per
benchmark, but the absolute epistemic rules (e.g. data-insufficient → escalate) are never
overridden by a learned threshold.
