# Methodology — Replication Levels

`REEXECUTION` (same seed/code/env) < `COMPUTATIONAL_REPRODUCTION` < `DIRECT_REPLICATION` <
`CONCEPTUAL_REPLICATION` < `EXTERNAL_VALIDATION` < `CROSS_DOMAIN_VALIDATION`.

Only the last four count as independent replication. A re-execution with the same seed
reproduces a computation; it is NOT a scientific replication and never increases independent
support. Each replica records data, code, equipment, environment, operators, methodology,
differences, result, and independence.
