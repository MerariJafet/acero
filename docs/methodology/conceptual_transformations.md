# Conceptual Transformations

Deep changes of interpretation (gravity-as-force → gravity-as-geometry;
heat-as-fluid → heat-as-energy-transfer; atom-as-indivisible → atom-as-quantum-system)
are represented as `ConceptualTransformation` records: previous/new model, preserved
predictions, changed assumptions, new explanatory power, unresolved problems,
triggering evidence, compatibility, replacement scope. Transformations are appended to
a concept's `historical_versions` (VERSIONED — the prior representation is never
deleted) and are NOT automatically marked as progress (`assessed_as_progress=None`
until evaluated).
