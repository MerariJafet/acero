# First Principles Reasoning

Reasoning proceeds from constraints — dimensions, symmetries, conservation, limiting
cases — to candidate models, then verifies. Dimensional analysis yields the scaling
(dimensionless groups) but NOT the numeric constant; that requires the full equations
or an experiment (explicitly disclosed). Symmetry→conservation is a documented
Noether-inspired association, not a proof. Derivation steps proposed by Codex are
verified by SymPy (symbolic identities must vanish); unresolved steps are tracked and
confidence is capped below 1. Model selection weighs parsimony, generalisation, and
constraint satisfaction — not just fit — and distinguishes prediction from
explanation.
